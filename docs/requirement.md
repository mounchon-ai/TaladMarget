# ต้องกาพัฒนาระบบสำหรับร้านขายผลไม้และสินค้าทั่วไป

1. หน้าขายสินค้า (Sales Screen)
   - แสดงรายการสินค้าเป็นตะกร้าไอคอน/การ์ด พร้อมรูปภาพสินค้าให้พนักงานเลือกกดขายได้ง่าย
   - ค้นหาสินค้าด้วยชื่อหรือบาร์โค้ดได้
   - เพิ่ม/ลด/ลบสินค้าในตะกร้าก่อนชำระเงิน

2. ระบบสมาชิก (Membership)
   - สมัครสมาชิกด้วยเบอร์โทร/ชื่อ
   - ผูกยอดซื้อสะสมกับสมาชิกแต่ละคน
   - ค้นหาสมาชิกตอนขายเพื่อรับสิทธิ์ส่วนลด

3. ระบบพนักงานขาย (Staff/Cashier)
   - พนักงานล็อกอินก่อนเข้าใช้งานหน้าขาย
   - บันทึกว่าออเดอร์แต่ละรายการขายโดยพนักงานคนไหน

4. ระบบสต็อกสินค้า (Stock)
   - เพิ่ม/แก้ไข/ลบสินค้า พร้อมรูปภาพ ราคา และจำนวนคงเหลือ
   - ตัดสต็อกอัตโนมัติเมื่อขายสำเร็จ
   - แจ้งเตือนเมื่อสินค้าใกล้หมด
   - Export Excel

5. ระบบโปรโมชั่น (Promotion)
   - ตั้งส่วนลดเป็น % ต่อสินค้าหรือทั้งบิล
   - ส่วนลดพิเศษสำหรับสมาชิก (% แยกจากโปรโมชั่นทั่วไป)
   - ซื้อ x แถม y
   - ซื้อ a + b แถม y
   - ซื้อ a + b ลด y%
   - ซื้อ x ชิ้น ลด y%
   - กำหนดช่วงวันที่เริ่ม-สิ้นสุดโปรโมชั่นได้

6. การบันทึกยอดขาย (Sales Record)
   - บันทึกทุกบิลขาย พร้อมรายการสินค้า ราคา ส่วนลด พนักงาน และสมาชิก (ถ้ามี)
   - ดูประวัติการขายย้อนหลังได้
   - Export Excel

7. รายงาน (Reports) ทุกรายงาน Export Excel ได้
   - รายงานยอดขายรายวัน/รายเดือน
   - รายงานสินค้าขายดี
   - รายงานยอดขายแยกตามพนักงาน
   - รายงานสต็อกคงเหลือ

## Tech
web : react + tailwind v5 + daisy v4
api : .net 10 api
database : postgresql v18

## รูปแบบเวป 
 - เป็น web responsive รองรับได้หลายขนาดหน้าจอ
 - left nav menu 
 - table รองรับ server paging  , search filter และมีปุ่ม search
