# BR-talad-031@v1

## ข้อความของกฎ
พนักงานขายทุกคนค้นหาและเห็นสมาชิกได้ทุกคนของร้าน ไม่จำกัดว่าใครเป็นคนสมัครให้ · ผลค้นหาแสดงชื่อ เบอร์โทรเต็ม และยอดซื้อสะสมของสมาชิก

## ที่มา

> "QB-scope-01 (สมาชิก): พนักงานขายค้นหา/เห็นสมาชิกได้แค่ไหน → b) เห็นสมาชิกทุกคนของร้าน ไม่ว่าใครสมัครให้ (ไม่เลือก ⭐ a เห็นเฉพาะที่ตัวเองสร้าง เพราะขัด BR-talad-004)"
> — [SRC-010](../sources/SRC-010.md) หน้า — §—

> "ตามต่อ QB-scope-01: ตอนค้นสมาชิกที่หน้าขาย พนักงานขายเห็นข้อมูลสมาชิกแค่ไหน → a) เห็นทุกอย่าง รวมยอดสะสม (ชื่อ เบอร์เต็ม ยอดซื้อสะสม)"
> — [SRC-010](../sources/SRC-010.md) หน้า — §—
