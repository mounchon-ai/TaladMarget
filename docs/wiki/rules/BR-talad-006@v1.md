# BR-talad-006@v1

## ข้อความของกฎ
ทุกบิลขายบันทึกผู้ขาย คือผู้ใช้ที่เปิดตะกร้าและกดชำระเงินบิลนั้น — เป็นได้ทั้งพนักงานขายและเจ้าของร้าน

## ที่มา

> "- บันทึกว่าออเดอร์แต่ละรายการขายโดยพนักงานคนไหน"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "QB-lang-01: "ออเดอร์" (SRC-001 บรรทัด 15) กับ "บิลขาย" (SRC-001 บรรทัด 33) เป็นสิ่งเดียวกันไหม → a) สิ่งเดียวกัน — ใช้คำเดียวทั้งเอกสาร โค้ด และ UI"
> — [SRC-003](../sources/SRC-003.md) หน้า — §—

> "ค้างจากชั้น 1: เจ้าของร้านขายหน้าร้านเองได้ไหม และรายงานยอดขายแยกตามพนักงาน (SRC-001 บรรทัด 40) นับเจ้าของร้านด้วยไหม → a) ขายได้ และนับในรายงาน — เจ้าของร้านทำทุกอย่างที่พนักงานขายทำได้ บิลบันทึกเจ้าของร้านเป็นผู้ขาย"
> — [SRC-005](../sources/SRC-005.md) หน้า — §—

- [EX-talad-039](../examples/EX-talad-039.md) — boundary: บิล 120 บาทแสดงผู้ขายเป็น มานี · บิล 90 บาทแสดงผู้ขายเป็น สมชาย (somchai) — ผู้ขายคือคนเปิดตะกร้า ไม่ใช่คนที่ใช้เครื่องก่อนหน้า
