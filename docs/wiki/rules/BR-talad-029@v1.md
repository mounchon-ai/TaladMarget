# BR-talad-029@v1

## ข้อความของกฎ
สินค้าแต่ละรายการในตะกร้าใช้โปรโมชั่นระดับสินค้าได้เพียงโปรเดียว — ถ้าเข้าเงื่อนไขหลายโปร ระบบเลือกโปรที่ลูกค้าได้ลดมากที่สุดให้อัตโนมัติ · ส่วนลดทั้งบิลคิดทีหลังจากยอดที่เหลือหลังหักโปรระดับสินค้าแล้ว

## ที่มา

> "ค้างจาก capture (BR-talad-009, 011-014): สินค้าชิ้นเดียวเข้าเงื่อนไขโปรหลายอันพร้อมกัน → a) โปรเดียวต่อสินค้า ระบบเลือกอันที่ลูกค้าได้ลดมากสุดให้อัตโนมัติ — ส่วนลดทั้งบิลคิดทีหลังจากยอดที่เหลือ"
