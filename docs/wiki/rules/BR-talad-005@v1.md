# BR-talad-005@v1

## ข้อความของกฎ
ผู้ใช้ต้องล็อกอินด้วยชื่อผู้ใช้และรหัสผ่านก่อนเข้าใช้งานหน้าขาย · ล็อกอินไม่สำเร็จ ระบบบอกแยกว่าไม่พบชื่อผู้ใช้ หรือรหัสผ่านไม่ถูกต้อง · เปิดหน้าขายโดยยังไม่ล็อกอิน ระบบพาไปหน้าล็อกอิน และล็อกอินแล้วกลับมาหน้าขาย

> — [SRC-020](../sources/SRC-020.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-005@v1: ล็อกอินไม่สำเร็จ พนักงานเห็นข้อความอะไร → b) บอกแยกว่าผิดตรงไหน — "ไม่พบชื่อผู้ใช้" / "รหัสผ่านไม่ถูกต้อง""
> — [SRC-020](../sources/SRC-020.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-005@v1: เปิดหน้าขายตรง ๆ โดยยังไม่ล็อกอิน → a) พาไปหน้าล็อกอิน ไม่มีข้อความ — ล็อกอินแล้วกลับมาหน้าขาย"
> — [SRC-020](../sources/SRC-020.md) หน้า — §—
