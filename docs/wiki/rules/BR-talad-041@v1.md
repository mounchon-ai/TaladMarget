# BR-talad-041@v1

## ข้อความของกฎ
การบันทึกรายการปรับสต็อกหนึ่งครั้งเกิดรายการเดียว — กดบันทึกซ้ำหรือส่งซ้ำ ครั้งหลังไม่สำเร็จ ไม่ปรับจำนวนคงเหลือซ้ำ และระบบแจ้ง error

## ที่มา

> "QB-idem-01 (บันทึกปรับสต็อกซ้ำ): เจ้าของร้านกดบันทึกรายการปรับสต็อก (BR-talad-032) สองครั้งติด หรือเน็ตหลุดแล้วส่งซ้ำ ระบบทำยังไง → a) กันซ้ำ แจ้ง error ⭐"
> — [SRC-015](../sources/SRC-015.md) หน้า — §—
