# BR-talad-030@v1

## ข้อความของกฎ
เบอร์โทรสมาชิกห้ามซ้ำกับสมาชิกที่ยังใช้งานอยู่ — เบอร์โทรหนึ่งเบอร์เป็นของสมาชิกที่ใช้งานอยู่ได้คนเดียว · สมัครด้วยเบอร์ที่มีสมาชิกใช้อยู่แล้ว (รวมถึงกดบันทึกซ้ำ) หรือแก้เบอร์ให้ไปซ้ำกับสมาชิกคนอื่น ไม่สำเร็จ และระบบแจ้ง error · สมาชิกที่ถูกซ่อนตาม BR-talad-040 ไม่นับตอนตรวจซ้ำ

## ที่มา

> "QB-idem-01 (BR-talad-002): มีสมาชิกเบอร์ 0812345678 อยู่แล้ว พนักงานกดสมัครด้วยเบอร์เดิมอีก (หรือกดบันทึกซ้ำ) ระบบทำยังไง → a) กันไม่ให้ซ้ำ แจ้ง error — เบอร์โทรหนึ่งเบอร์ = สมาชิกหนึ่งคน"
> — [SRC-009](../sources/SRC-009.md) หน้า — §—

> "ตามต่อ QB-idem-01 (แก้เบอร์สมาชิก): เบอร์ใหม่ต้องผ่านกฎเดียวกับตอนสมัครไหม (10 หลักขึ้นต้น 0 ตาม BR-talad-002 · ห้ามซ้ำตาม BR-talad-030) → a) ผ่านกฎเดียวกัน ⭐ — แก้เป็นเบอร์ที่คนอื่นใช้อยู่ หรือไม่ครบ 10 หลัก บันทึกไม่สำเร็จ แจ้ง error"
> — [SRC-014](../sources/SRC-014.md) หน้า — §—

> "ค้างจากรอบก่อน (สมาชิกที่ถูกซ่อนตาม BR-talad-040 ยังถือเบอร์ไหม): มาสมัครด้วยเบอร์เดิม เกิดอะไรขึ้น → b) ปล่อยเบอร์ สมัครใหม่ได้ — สมาชิกที่ถูกซ่อนไม่นับตอนตรวจซ้ำ สมัครใหม่ได้เป็นสมาชิกคนใหม่ ยอดสะสมเริ่มที่ 0"
> — [SRC-015](../sources/SRC-015.md) หน้า — §—

## พิสูจน์โดย

- [EX-talad-005](../examples/EX-talad-005.md) — happy: ระบบแสดง "สมัครสมาชิกสำเร็จ" · ค้นหาเบอร์ 0812345678 ที่หน้าขายเจอสมาชิก สมหญิง ใจดี
- [EX-talad-009](../examples/EX-talad-009.md) — exception: ระบบแสดง "เบอร์โทรนี้เป็นสมาชิกอยู่แล้ว" · ไม่มีสมาชิกใหม่ถูกสร้าง — ค้นหาเบอร์ 0812345678 ที่หน้าขายเจอแค่ สมหญิง ใจดี คนเดียว
- [EX-talad-010](../examples/EX-talad-010.md) — alternate: ระบบแสดง "เบอร์โทรนี้เป็นสมาชิกอยู่แล้ว" · เบอร์ของมานะยังเป็น 0898765432 เหมือนเดิม
- [EX-talad-011](../examples/EX-talad-011.md) — boundary: ระบบแสดง "สมัครสมาชิกสำเร็จ" · ค้นหาเบอร์ 0812345678 ที่หน้าขายเจอ สมศรี มีสุข ยอดซื้อสะสม 0 บาท (ไม่เจอ สมหญิง)
