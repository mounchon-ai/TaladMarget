# BR-talad-007@v1

## ข้อความของกฎ
เมื่อขายสำเร็จ ระบบตัดสต็อกของสินค้าที่ขายโดยอัตโนมัติ รวมถึงของแถม (และคืนเมื่อยกเลิกบิลตาม BR-talad-024) · ตะกร้าที่ยังไม่ชำระไม่ตัดและไม่จองสต็อก · ขายเกินจำนวนคงเหลือไม่ได้ — หยิบหรือกด "+" เกินคงเหลือไม่ได้ และถ้าตอนกดชำระสต็อกไม่พอแล้วก็ชำระไม่ได้ ทั้งสองกรณีระบบแสดง "<ชื่อสินค้า> คงเหลือไม่พอ (เหลือ <จำนวน>)"
