# BR-talad-039@v1

## ข้อความของกฎ
ตะกร้าหนึ่งใบชำระเงินได้ครั้งเดียว — กดชำระเงินซ้ำหรือส่งซ้ำ ครั้งหลังไม่สำเร็จ ไม่เกิดบิลขายที่สอง ไม่ตัดสต็อกและไม่เพิ่มยอดซื้อสะสมซ้ำ และระบบแจ้ง error

## ที่มา

> "QB-idem-01 (กดชำระเงินซ้ำ): พนักงานกดปุ่มชำระเงินสองครั้งติด หรือเน็ตหลุดแล้วส่งซ้ำ ระบบทำยังไง → a) กันซ้ำ แจ้ง error ⭐ — ตะกร้าหนึ่งใบชำระได้ครั้งเดียว"
> — [SRC-014](../sources/SRC-014.md) หน้า — §—
