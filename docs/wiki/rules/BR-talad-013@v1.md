# BR-talad-013@v1

## ข้อความของกฎ
โปรโมชั่นแบบ ซื้อ a + b ลด y% — เจ้าของร้านตั้งจำนวน a และ b ต่อชุดได้ · นับชุดตามฝั่งที่ครบน้อยกว่า · ลด y% เฉพาะชิ้นที่อยู่ในชุดครบคู่ ชิ้นที่เกินคิดราคาปกติ · ส่วนลดคิดและปัดแยกต่อบรรทัด a และ b

คำนวณตามสัญญา [CALC-talad-006@v1](../calculations/CALC-talad-006@v1.md)

## ที่มา

> "- ซื้อ a + b ลด y%"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "①a โปร ซื้อ a + b ลด y% ต้องซื้อ a กับ b อย่างละกี่ชิ้นต่อ 1 ชุด → a) ตั้งจำนวนของ a, b ได้ — เจ้าของร้านตั้ง n_a, n_b ต่อชุดเอง แบบเดียวกับ BR-talad-012 · นับชุดตามฝั่งที่ครบน้อยกว่า (min)"
> — [SRC-037](../sources/SRC-037.md) หน้า — §—

> "①b ครบชุดแล้ว ลด y% จากอะไร (โปรซื้อส้ม 1 + มังคุด 1 ลด 10% ตะกร้ามีส้ม 3 มังคุด 1) → a) ลดเฉพาะชิ้นที่อยู่ในชุดครบคู่ — ชิ้นที่เกินคิดราคาปกติ"
> — [SRC-037](../sources/SRC-037.md) หน้า — §—

> "⑤ rounding_points → a) ปัดแยกต่อบรรทัด a และ b — ส่วนลดของแต่ละบรรทัดปัด HALF_UP ที่ 0.01 ครั้งเดียว แบบเดียวกับ CALC-talad-003"
> — [SRC-037](../sources/SRC-037.md) หน้า — §—
