# BR-talad-023@v1

## ข้อความของกฎ
ยกเลิกบิลขายได้เฉพาะบิลที่ขายในวันนี้ — ระบบไม่มีขั้นตอนปิดยอด ขึ้นวันใหม่แล้วบิลของวันก่อนหน้ายกเลิกไม่ได้ · บิลของวันก่อนหน้าไม่มีปุ่มยกเลิก

## ที่มา

> "QB-rev-02: ยกเลิก/แก้บิลย้อนหลังได้ลึกแค่ไหน → c) เฉพาะบิลของวันที่ยังไม่ปิดยอด — ปิดยอดวันแล้วแตะไม่ได้"
> — [SRC-006](../sources/SRC-006.md) หน้า — §—

> "QB-frz-01: บิลที่ชำระแล้ว (ยังไม่ปิดยอด) ยังแก้รายการได้ไหม หรือต้องยกเลิกอย่างเดียว → c) แก้ไม่ได้ — ยกเลิกแล้วขายใหม่ (ตัดคำว่า "แก้" ออกจาก BR-talad-019 / BR-talad-023)"
> — [SRC-007](../sources/SRC-007.md) หน้า — §—

> "ต่อยอด BR-talad-023: ปิดยอดประจำวันเกิดขึ้นยังไง → c) ไม่มีปุ่มปิดยอด — ยกเลิกได้เฉพาะบิลของ "วันนี้" ขึ้นวันใหม่ถือว่าบิลของวันก่อนปิดแล้วโดยปริยาย"
> — [SRC-007](../sources/SRC-007.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-023@v1: เจ้าของร้านเปิดบิลของเมื่อวาน (ยกเลิกไม่ได้) เห็นอะไร → a) ไม่มีปุ่มยกเลิก — บิลของวันก่อนหน้าไม่มีปุ่มยกเลิกเลย"
> — [SRC-023](../sources/SRC-023.md) หน้า — §—
