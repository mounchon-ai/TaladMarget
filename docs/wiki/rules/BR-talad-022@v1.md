# BR-talad-022@v1

## ข้อความของกฎ
รายงานยอดขายแยกตามพนักงานนับบิลที่เจ้าของร้านขายด้วย โดยเจ้าของร้านมีแถวของตัวเองเหมือนผู้ขายคนหนึ่ง · ยอดขายของแต่ละแถวคือผลรวมยอดชำระจริง (หลังส่วนลด) ของบิลที่คนนั้นเป็นผู้ขาย ไม่นับบิลที่ยกเลิก · ผู้ขายที่ไม่มียอดในช่วงที่เลือกแสดงแถวยอด 0

## ที่มา

> "- รายงานยอดขายแยกตามพนักงาน"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "ค้างจากชั้น 1: เจ้าของร้านขายหน้าร้านเองได้ไหม และรายงานยอดขายแยกตามพนักงาน (SRC-001 บรรทัด 40) นับเจ้าของร้านด้วยไหม → a) ขายได้ และนับในรายงาน — เจ้าของร้านทำทุกอย่างที่พนักงานขายทำได้ บิลบันทึกเจ้าของร้านเป็นผู้ขาย"
> — [SRC-005](../sources/SRC-005.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-022@v1: ยอดขายในรายงานยอดขายแยกตามพนักงานคือยอดอะไร → a) ยอดชำระจริง (หลังส่วนลด)"
> — [SRC-033](../sources/SRC-033.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-022@v1: พนักงานที่ไม่มียอดขายในช่วงที่เลือก แสดงในรายงานไหม → a) แสดง ยอด 0 — ทุกคนที่มีบัญชีมีแถวเสมอ"
> — [SRC-033](../sources/SRC-033.md) หน้า — §—
