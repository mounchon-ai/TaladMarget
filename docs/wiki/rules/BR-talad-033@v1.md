# BR-talad-033@v1

## ข้อความของกฎ
การแก้ราคาสินค้าทุกครั้งบันทึกประวัติราคา — ราคาเดิม ราคาใหม่ ผู้แก้ และเวลา · ประวัติเดิมคงไว้ ไม่ถูกทับ

## ที่มา

> "QB-aud-01 (ราคาสินค้า): เจ้าของร้านแก้ราคาสินค้าในระบบ เก็บร่องรอยยังไง → b) เก็บประวัติราคา ค่าเดิมคงไว้ ⭐ — ทุกครั้งที่แก้เกิดแถวประวัติ (ราคาเดิม → ราคาใหม่ คนแก้ เวลา)"
> — [SRC-011](../sources/SRC-011.md) หน้า — §—
