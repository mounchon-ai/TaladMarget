# BR-talad-014@v1

## ข้อความของกฎ
โปรโมชั่นแบบ ซื้อ x ชิ้น ลด y% — ผูกกับสินค้าตัวเดียว นับจำนวนจากบรรทัดของสินค้านั้น · นับเป็นชุดละ x ชิ้น ลด y% ซ้ำตามจำนวนชุด ชิ้นที่ไม่ครบชุดคิดราคาปกติ · ส่วนลดคิดและปัดครั้งเดียวต่อบรรทัด

คำนวณตามสัญญา [CALC-talad-007@v1](../calculations/CALC-talad-007@v1.md)

## ที่มา

> "- ซื้อ x ชิ้น ลด y%"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "①a โปร ซื้อ x ชิ้น ลด y% (โปรซื้อส้ม 3 ชิ้น ลด 10% ตะกร้ามีส้ม 7 ชิ้น) ลดให้กี่ชิ้น → a) 6 ชิ้น — นับเป็นชุดละ x ชิ้น ลดซ้ำตามชุด ชิ้นที่เกินคิดราคาปกติ แบบเดียวกับ BR-talad-013"
> — [SRC-039](../sources/SRC-039.md) หน้า — §—

> "①b นับ x ชิ้นจากอะไร → a) สินค้าเดียวกัน — โปรหนึ่งอันผูกสินค้าตัวเดียว นับจากจำนวนในบรรทัดนั้น"
> — [SRC-039](../sources/SRC-039.md) หน้า — §—
