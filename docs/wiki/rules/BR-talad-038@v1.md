# BR-talad-038@v1

## ข้อความของกฎ
ตะกร้าคิดราคา โปรโมชั่น และส่วนลดสมาชิกตามค่า ณ ตอนกดชำระเงิน — ถ้าระหว่างที่ตะกร้าเปิดอยู่มีการแก้ราคา หรือโปรโมชั่นหมดช่วงเวลา ยอดที่ชำระใช้ค่าล่าสุด ณ ตอนกดชำระ

## ที่มา

> "ตามต่อ QB-tmp-01 (ตะกร้าที่ยังเปิดอยู่): หยิบของใส่ตะกร้าแล้ว ระหว่างนั้นเจ้าของร้านแก้ราคา หรือโปรโมชั่นหมดเวลา ตอนกดชำระเงินคิดตามค่าไหน → a) คิดตามค่า ณ ตอนกดชำระเงิน"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

## พิสูจน์โดย

- [EX-talad-024](../examples/EX-talad-024.md) — alternate: ยอดที่ชำระ 90 บาท (ใช้ส่วนลดสมาชิก 10% ไม่ใช่ 5%)
- [EX-talad-025](../examples/EX-talad-025.md) — boundary: ยอดที่ชำระ 90 บาท — โปรโมชั่นหมดช่วงแล้ว ณ ตอนกดชำระ จึงไม่ได้ลด 10%
- [EX-talad-026](../examples/EX-talad-026.md) — boundary: ยอดที่ชำระ 81 บาท — โปรโมชั่นเริ่มมีผลแล้ว ณ ตอนกดชำระ จึงได้ลด 10%
