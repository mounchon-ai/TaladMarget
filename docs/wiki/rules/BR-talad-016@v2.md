# BR-talad-016@v2

## ข้อความของกฎ
ทุกบิลขายต้องบันทึกรายการสินค้า ราคา ส่วนลด พนักงาน และสมาชิก (ถ้ามี) · บรรทัดสินค้าที่ได้โปรโมชั่นระดับสินค้าแสดงชื่อโปรและส่วนลดของบรรทัดนั้นใต้บรรทัดสินค้า (เช่น "โปร: ส้มสายน้ำผึ้ง ลด 10% − 13.50 บาท") และบิลยังแสดงยอด "ส่วนลดโปรโมชั่น" รวม

## ที่มา

> "- บันทึกทุกบิลขาย พร้อมรายการสินค้า ราคา ส่วนลด พนักงาน และสมาชิก (ถ้ามี)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-029@v1: บิลแสดงชื่อโปรที่ใช้ไหม → a) แสดงใต้บรรทัดสินค้า เช่น "โปร: ส้ม ลด 10% − 13.50 บาท" และยังมียอด "ส่วนลดโปรโมชั่น" รวม"
> — [SRC-041](../sources/SRC-041.md) หน้า — §—
