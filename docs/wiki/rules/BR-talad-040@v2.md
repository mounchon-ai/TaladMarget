# BR-talad-040@v2

## ข้อความของกฎ
สมาชิกทุกคน ไม่ว่ามีบิลขายผูกอยู่หรือไม่ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่ซ่อน — ค้นหาที่หน้าขายไม่เจออีก แต่บิลเก่า (ถ้ามี) ยังแสดงชื่อสมาชิกครบ · เบอร์ของสมาชิกที่ถูกซ่อนถูกปล่อย สมัครใหม่ด้วยเบอร์นั้นได้เป็นสมาชิกคนใหม่ ยอดซื้อสะสมเริ่มที่ 0

## ที่มา

> "ตามต่อจากรอบ permission (ลบสมาชิกที่มีบิลผูกอยู่แล้ว): เกิดอะไรขึ้น → a) ซ่อน ไม่ลบจริง — ค้นไม่เจอแล้ว แต่บิลเก่ายังแสดงชื่อสมาชิกครบ"
> — [SRC-014](../sources/SRC-014.md) หน้า — §—

> "ค้างจากรอบก่อน (สมาชิกที่ถูกซ่อนตาม BR-talad-040 ยังถือเบอร์ไหม): มาสมัครด้วยเบอร์เดิม เกิดอะไรขึ้น → b) ปล่อยเบอร์ สมัครใหม่ได้ — สมาชิกที่ถูกซ่อนไม่นับตอนตรวจซ้ำ สมัครใหม่ได้เป็นสมาชิกคนใหม่ ยอดสะสมเริ่มที่ 0"
> — [SRC-015](../sources/SRC-015.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-037@v1: สมาชิกที่ยังไม่เคยซื้อ (ไม่มีบิลผูก) เจ้าของลบแล้วเกิดอะไร → b) ซ่อนเหมือนกัน — ทุกการลบสมาชิกเป็นซ่อนหมด (เบอร์ถูกปล่อยตาม BR-talad-040)"
> — [SRC-027](../sources/SRC-027.md) หน้า — §—
