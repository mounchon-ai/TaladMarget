# BR-talad-037@v1

## ข้อความของกฎ
สินค้าหรือโปรโมชั่นทุกรายการ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่เปลี่ยนเป็นเลิกขาย ไม่ว่าเคยถูกขายในบิลแล้วหรือไม่ — หายจากหน้าขายและหน้าจัดการ แต่บิลเก่ายังแสดงสินค้า ราคา และส่วนลดเดิมครบ · สินค้าที่อยู่ในตะกร้าที่ยังเปิดอยู่เมื่อถูกลบ ชำระไม่ได้ ระบบแสดง "<ชื่อสินค้า> เลิกขายแล้ว กรุณาเอาออกจากตะกร้า"
