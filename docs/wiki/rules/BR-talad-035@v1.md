# BR-talad-035@v1

## ข้อความของกฎ
การแก้ราคาสินค้า โปรโมชั่น หรือ % ส่วนลดสมาชิก มีผลเฉพาะบิลที่ชำระเงินหลังจากแก้ — บิลที่ขายไปแล้วคงราคาและส่วนลด ณ ตอนขาย ไม่ถูกคำนวณใหม่
