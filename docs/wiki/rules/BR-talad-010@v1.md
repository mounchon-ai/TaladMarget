# BR-talad-010@v1

## ข้อความของกฎ
สมาชิกได้ส่วนลดพิเศษเป็น % เดียวกันทั้งร้าน ที่เจ้าของร้านตั้งแยกจากโปรโมชั่นทั่วไป (% เต็ม 0–100) · ไม่มีช่วงเวลา มีผลตลอดจนกว่าจะแก้ · ตั้ง 0% = ไม่มีส่วนลดสมาชิก · ใช้กับบิลที่ผูกสมาชิกเท่านั้น

## ที่มา

> "- ส่วนลดพิเศษสำหรับสมาชิก (% แยกจากโปรโมชั่นทั่วไป)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-010@v1: ส่วนลดสมาชิก % ตั้งแบบไหน → a) ค่าเดียวทั้งร้าน — เจ้าของตั้ง % เดียว สมาชิกทุกคนได้เท่ากัน"
> — [SRC-030](../sources/SRC-030.md) หน้า — §—

> "ระหว่าง /req:example BR-talad-010@v1: ส่วนลดสมาชิกมีช่วงเวลาเหมือนโปรโมชั่นไหม → a) ไม่มี — มีผลตลอด ตั้งแล้วใช้ได้เรื่อย ๆ จนกว่าจะแก้ · ตั้ง 0% = ปิดส่วนลดสมาชิก"
> — [SRC-030](../sources/SRC-030.md) หน้า — §—

> "② inputs → % ส่วนลด (ทั้งบิล และสมาชิก) เป็น % เต็มเท่านั้น (0–100) · ราคา = เงิน 2 ตำแหน่ง · จำนวน = จำนวนเต็ม"
> — [SRC-028](../sources/SRC-028.md) หน้า — §—
