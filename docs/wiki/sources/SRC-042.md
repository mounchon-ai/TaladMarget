## เนื้อความ

> ①a ส่วนลดสมาชิกคิดจากยอดไหน → a) ยอดหลังโปรและหลังส่วนลดทั้งบิล — after_bill ตาม CALC-talad-001 / BR-talad-028 คิดต่อกัน ไม่บวก % กัน ①b % สมาชิกที่ใช้คิด เอาค่า ณ ตอนไหน → a) ค่าที่ตั้งอยู่ ณ ตอนกดชำระ — แก้ % ระหว่างตะกร้าเปิดอยู่ ใช้ค่าใหม่ (ตรงกับ EX-talad-024) ยืนยันสูตร: member_rate = (บิลผูกสมาชิก ? % สมาชิกของร้าน ณ ตอนกดชำระ : 0) · member_discount = ปัด(after_bill × member_rate ÷ 100) · net = after_bill − member_discount (ตาม CALC-talad-001) → ถูก ②–⑥ → ถูกทุกข้อ: shop_member_rate = int % 0–100 · has_member = ใช่/ไม่ · after_bill = money(2) จาก CALC-talad-001 · decimal · HALF_UP · ปัดครั้งเดียวที่ member_discount 0.01 · residual ไม่มี ⑦ boundary_behavior → ยืนยันทั้งหมด: บิลไม่ผูกสมาชิก → ไม่ลด แม้ร้านตั้ง % ไว้ · ตั้ง 0% → ไม่ลด (ยอดซื้อสะสมยังสะสม) · ตั้ง 100% → ยอดชำระ 0 ชำระได้ · แก้ % ระหว่างตะกร้าเปิด → ใช้ค่า ณ ตอนชำระ · after_bill = 0 → ไม่ลด · สมาชิกทุกคนได้ % เท่ากัน · ส่วนลดมีเศษ → ปัด HALF_UP ที่ 0.01
