## เนื้อความ

> ① formula → ถูก — ยอดรายการ = ราคา×จำนวน − ส่วนลดโปรระดับสินค้า (โปรเดียวที่ลดมากสุด) → ยอดรวม = Σ ยอดรายการ → ส่วนลดทั้งบิล = ยอดรวม × %บิล → หลังบิล = ยอดรวม − ส่วนลดทั้งบิล → ส่วนลดสมาชิก = หลังบิล × %สมาชิก → ยอดสุทธิ = หลังบิล − ส่วนลดสมาชิก ② inputs → % ส่วนลด (ทั้งบิล และสมาชิก) เป็น % เต็มเท่านั้น (0–100) · ราคา = เงิน 2 ตำแหน่ง · จำนวน = จำนวนเต็ม ③ numeric_type → decimal ④ rounding_mode → HALF_UP (ยืนยันตาม BR-talad-027) ⑤ rounding_points → ทุกจุดส่วนลด · 2 ตำแหน่ง (สตางค์) — ปัดทันทีที่คำนวณส่วนลดโปรต่อรายการ ส่วนลดทั้งบิล และส่วนลดสมาชิก ที่ 0.01 บาท ⑥ residual_policy → ไม่มีเศษ (null) — ส่วนลดทั้งบิลและสมาชิกคิดที่ยอดรวม ไม่กระจายลงรายการ ⑦ boundary_behavior → ยืนยันทั้ง 4 ข้อ: ไม่มีสมาชิก/ไม่มีส่วนลดทั้งบิล = ส่วนลดนั้น 0 · % = 100 ได้ ยอดสุทธิ 0 ชำระได้ · ยอดสุทธิไม่ติดลบเสมอ · ยอดรวม 0 (ของแถมล้วน) → ส่วนลดทุกขั้น 0
