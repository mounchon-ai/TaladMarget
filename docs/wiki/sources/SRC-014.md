## เนื้อความ

> ตามต่อ QB-idem-01 (แก้เบอร์สมาชิก): เบอร์ใหม่ต้องผ่านกฎเดียวกับตอนสมัครไหม (10 หลักขึ้นต้น 0 ตาม BR-talad-002 · ห้ามซ้ำตาม BR-talad-030) → a) ผ่านกฎเดียวกัน ⭐ — แก้เป็นเบอร์ที่คนอื่นใช้อยู่ หรือไม่ครบ 10 หลัก บันทึกไม่สำเร็จ แจ้ง error QB-idem-01 (กดชำระเงินซ้ำ): พนักงานกดปุ่มชำระเงินสองครั้งติด หรือเน็ตหลุดแล้วส่งซ้ำ ระบบทำยังไง → a) กันซ้ำ แจ้ง error ⭐ — ตะกร้าหนึ่งใบชำระได้ครั้งเดียว ตามต่อจากรอบ permission (ลบสมาชิกที่มีบิลผูกอยู่แล้ว): เกิดอะไรขึ้น → a) ซ่อน ไม่ลบจริง — ค้นไม่เจอแล้ว แต่บิลเก่ายังแสดงชื่อสมาชิกครบ
