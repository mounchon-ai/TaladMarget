## เนื้อความ

> QB-scope-01 (สมาชิก): พนักงานขายค้นหา/เห็นสมาชิกได้แค่ไหน → b) เห็นสมาชิกทุกคนของร้าน ไม่ว่าใครสมัครให้ (ไม่เลือก ⭐ a เห็นเฉพาะที่ตัวเองสร้าง เพราะขัด BR-talad-004) QB-scope-01 (ประวัติการขาย): พนักงานขายดูบิลขายย้อนหลังได้แค่ไหน → a) เห็นเฉพาะบิลที่ตัวเองขาย ⭐ — บิลของคนอื่นมองไม่เห็น ตามต่อ QB-scope-01: ตอนค้นสมาชิกที่หน้าขาย พนักงานขายเห็นข้อมูลสมาชิกแค่ไหน → a) เห็นทุกอย่าง รวมยอดสะสม (ชื่อ เบอร์เต็ม ยอดซื้อสะสม) ยืนยันการจัดประเภท: คำตอบบรรทัด 2 ชนกับ BR-talad-018@v1 ("ใช้ได้เฉพาะงานหน้าร้าน") → a) แก้ BR-talad-018 ในที่เดิม — เพิ่ม "ดูบิลขายที่ตัวเองขาย" เข้าในสิ่งที่พนักงานขายทำได้ การดูบิลของตัวเองไม่นับเป็น "รายงาน"
