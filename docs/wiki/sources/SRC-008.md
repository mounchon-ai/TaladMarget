## เนื้อความ

> QB-calc-01: ส่วนลด % ให้ผลมีเศษเกินสตางค์ (เช่น ลด 15% ของ 19.75 = 2.9625) ระบบทำยังไง → a) ปัดทุกจุดตามมาตรฐาน round half up ค้างจาก capture (BR-talad-009/010): ส่วนลดสมาชิก (%) กับโปรโมชั่นทั่วไปใช้พร้อมกันได้ไหม → a) ได้ทั้งคู่ คิดต่อกัน — คิดโปรทั่วไปก่อน แล้วลด % สมาชิกจากยอดที่เหลือ (100 → โปร 10% = 90 → สมาชิก 5% = 85.50) ค้างจาก capture (BR-talad-009, 011-014): สินค้าชิ้นเดียวเข้าเงื่อนไขโปรหลายอันพร้อมกัน → a) โปรเดียวต่อสินค้า ระบบเลือกอันที่ลูกค้าได้ลดมากสุดให้อัตโนมัติ — ส่วนลดทั้งบิลคิดทีหลังจากยอดที่เหลือ
