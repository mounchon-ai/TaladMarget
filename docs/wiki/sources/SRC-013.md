## เนื้อความ

> QB-perm-01 (Export Excel ประวัติการขาย): ใคร Export บิลเป็น Excel ได้ → b) พนักงานขายดูบิลของตัวเองบนจอได้ แต่ Export ได้เฉพาะเจ้าของร้าน ⭐ QB-perm-01 (แก้/ลบข้อมูลสมาชิก): ใครทำได้ → b) พนักงานขายแก้ชื่อ/เบอร์สมาชิกได้ · ลบสมาชิกได้เฉพาะเจ้าของร้าน ⭐ QB-perm-01 (พิมพ์ใบเสร็จซ้ำ): ใครพิมพ์ซ้ำได้ → b) พนักงานขายพิมพ์ซ้ำได้เฉพาะบิลที่ตัวเองขาย · เจ้าของร้านพิมพ์ซ้ำได้ทุกบิล ⭐ ยืนยันการจัดประเภท: บรรทัด 1-3 เปลี่ยนรายการ "ทำได้เฉพาะ" ใน BR-talad-018 และ "เฉพาะเจ้าของร้าน" ใน BR-talad-019 → a) แก้ BR-talad-018 และ BR-talad-019 ในที่เดิม
