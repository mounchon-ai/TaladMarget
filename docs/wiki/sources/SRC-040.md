## เนื้อความ

> ①a สินค้าเข้าเงื่อนไขหลายโปร "ลดมากที่สุด" เทียบด้วยค่าอะไร → a) ส่วนลดเป็นบาท หลังปัด — ส่วนลดรวมที่โปรนั้นให้ ตามสูตรของโปร (CALC-talad-003 ถึง 007) ①b สองโปรลดเท่ากันพอดี บิลแสดงโปรไหน → c) ให้พนักงานเลือก ①c โปรที่ครอบหลายบรรทัดชนกัน ("ส้ม 1 + มังคุด 1 ลด 10%" กับ "ซื้อส้ม 3 ชิ้น ลด 20%" แย่งบรรทัดส้ม) → a) ไล่ทีละโปร (greedy) — ใช้โปรที่ลดมากสุดก่อน บรรทัดที่ถูกใช้แล้วหลุดจากโปรอื่น แล้วคิดใหม่กับที่เหลือ ①d โปรส้ม 1 + มังคุด 1 ได้บรรทัดส้มไป (ตะกร้ามีส้ม 4) ส้ม 3 ชิ้นนอกชุดเข้าโปรอื่นต่อได้ไหม → a) ไม่ได้ — ทั้งบรรทัดใช้โปรเดียว ชิ้นนอกชุดคิดราคาปกติ ยืนยันสูตร: วนซ้ำ — คิดส่วนลด (บาท หลังปัดตาม CALC ของโปรนั้น) ของทุกโปรที่เข้าเงื่อนไข โดยใช้เฉพาะบรรทัดที่ยังว่าง → เลือกโปรที่ลดมากสุด (เท่ากัน → พนักงานเลือก) → บรรทัดที่โปรนั้นใช้หลุดจากรอบต่อไป → จนไม่มีโปรไหนลด > 0 · ส่วนลดทั้งบิลคิดทีหลังตาม CALC-talad-001/003 → ถูก ②③④⑤⑥ → ถูกทุกข้อ: อินพุต = บรรทัดในตะกร้า (สินค้า · qty int · ราคา money(2) ณ ตอนกดชำระ) + โปรระดับสินค้าที่เปิดอยู่ · decimal · HALF_UP · สัญญานี้ไม่ปัดเอง ใช้ค่าที่ปัดแล้วของแต่ละโปร · residual ไม่มี ⑦ boundary_behavior → ยืนยันทั้งหมด: ไม่มีโปรเข้าเงื่อนไข → ไม่ลด · เข้าโปรเดียว → ใช้โปรนั้น · โปรที่ลด 0 (y = 0 หรือยังไม่ครบชุด) ไม่ถูกเลือกและไม่กินบรรทัด · ลดเท่ากันที่อันดับสูงสุด → พนักงานเลือก · เทียบด้วยค่าหลังปัด ต่างกัน 0.01 ก็นับว่ามากกว่า · ราคา ณ ตอนกดชำระ (BR-talad-038)
