## เนื้อความ

> ①a โปร ซื้อ x ชิ้น ลด y% (โปรซื้อส้ม 3 ชิ้น ลด 10% ตะกร้ามีส้ม 7 ชิ้น) ลดให้กี่ชิ้น → a) 6 ชิ้น — นับเป็นชุดละ x ชิ้น ลดซ้ำตามชุด ชิ้นที่เกินคิดราคาปกติ แบบเดียวกับ BR-talad-013 ①b นับ x ชิ้นจากอะไร → a) สินค้าเดียวกัน — โปรหนึ่งอันผูกสินค้าตัวเดียว นับจากจำนวนในบรรทัดนั้น ยืนยันสูตร (ก่อนปัด): sets = ปัดลง(qty ÷ x) · ส่วนลด = sets × x × unit_price × y ÷ 100 · ลงเป็น item_promo_discount ของบรรทัดนั้น (CALC-talad-001) → ถูก ②③④⑥ → ถูกทุกข้อ: x = int ≥ 1 · y = % เต็ม 0–100 · qty = int · ราคา money(2) · decimal · HALF_UP · residual ไม่มี ⑤ rounding_points → a) ครั้งเดียวต่อบรรทัด — ส่วนลดของบรรทัดปัด HALF_UP ที่ 0.01 ครั้งเดียว (ไม่ปัดต่อชิ้น/ต่อชุด) แบบเดียวกับ CALC-talad-003/006 ⑦ boundary_behavior → ยืนยันทั้งหมด: qty < x → ไม่ลด · qty = x พอดี → ลด 1 ชุด · ชิ้นเกินชุดคิดราคาปกติ · ราคา ณ ตอนกดชำระ (BR-talad-038) · y = 0 → ไม่ลด · y = 100 → ชิ้นในชุดฟรี ยอดไม่ติดลบ · x = 1 → ลดทุกชิ้น
