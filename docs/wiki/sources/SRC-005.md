## เนื้อความ

> QB-perm-01: พนักงานขายทำสิ่งที่ย้อนกลับไม่ได้ไม่ได้ — ใครมีสิทธิ์ยกเลิก/แก้บิลที่ชำระแล้ว แก้ราคาหน้าขาย ลบสินค้า → b) เจ้าของร้านเท่านั้น QB-perm-02: พนักงานขายที่แก้ตะกร้า/กดชำระเงิน ต้องเป็นคนที่เปิดตะกร้านั้นไหม → a) เฉพาะคนที่เปิดตะกร้า ค้างจากชั้น 1: เจ้าของร้านขายหน้าร้านเองได้ไหม และรายงานยอดขายแยกตามพนักงาน (SRC-001 บรรทัด 40) นับเจ้าของร้านด้วยไหม → a) ขายได้ และนับในรายงาน — เจ้าของร้านทำทุกอย่างที่พนักงานขายทำได้ บิลบันทึกเจ้าของร้านเป็นผู้ขาย
