## เนื้อความ

> ระหว่าง /req:example BR-talad-026@v1: ชำระเงินสำเร็จแล้ว ใบเสร็จออกให้ลูกค้าอย่างไร → b) แสดงบนจอ กดพิมพ์เอง — หน้าจอแสดงใบเสร็จพร้อมปุ่มพิมพ์ พนักงานกดพิมพ์เมื่อลูกค้าต้องการ ระหว่าง /req:example BR-talad-026@v1: ยกเลิกบิลแล้ว ใบเสร็จเดิมถือว่ายกเลิก เห็นได้จากอะไร → b) พิมพ์ซ้ำไม่ได้ — บิลที่ยกเลิกแล้วไม่มีปุ่มพิมพ์ใบเสร็จ ดูได้แค่สถานะ "ยกเลิก" บนบิล ระหว่าง /req:example BR-talad-026@v1: บิลที่ขายใหม่แทนบิลที่ยกเลิก ใบเสร็จใบใหม่เกี่ยวกับใบเดิมยังไง → a) เลขใหม่ ไม่อ้างใบเดิม ยืนยันการจัดประเภท: EX-talad-004 (ตะกร้าว่างใบใหม่ทันที) กับ "ใบเสร็จแสดงบนจอ" อยู่ด้วยกันยังไง → b) ใบเสร็จก่อน แล้วค่อยตะกร้าใหม่ — แสดงใบเสร็จเต็มจอ พนักงานกดปิดแล้วจึงได้ตะกร้าว่าง (EX-talad-004 ต้องแก้)
