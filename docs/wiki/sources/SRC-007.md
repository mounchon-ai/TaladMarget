## เนื้อความ

> QB-frz-01: บิลที่ชำระแล้ว (ยังไม่ปิดยอด) ยังแก้รายการได้ไหม หรือต้องยกเลิกอย่างเดียว → c) แก้ไม่ได้ — ยกเลิกแล้วขายใหม่ (ตัดคำว่า "แก้" ออกจาก BR-talad-019 / BR-talad-023) ต่อยอด BR-talad-023: ปิดยอดประจำวันเกิดขึ้นยังไง → c) ไม่มีปุ่มปิดยอด — ยกเลิกได้เฉพาะบิลของ "วันนี้" ขึ้นวันใหม่ถือว่าบิลของวันก่อนปิดแล้วโดยปริยาย QB-frz-02: ระบบออกใบเสร็จให้ลูกค้าไหม และถ้าออกแล้วยกเลิก/แก้บิลจะทำยังไง → c) ออกใบเสร็จทุกบิล — ยกเลิกแล้วออกใบใหม่ทับ ใบเดิมถือว่ายกเลิก
