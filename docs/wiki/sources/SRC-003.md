## เนื้อความ

> QB-actor-01: นอกจากพนักงานขาย มีใครอีกที่แตะข้อมูลชุดนี้ → a) มีแค่พนักงานขาย + b) มีเจ้าของร้าน/ผู้ดูแลแยก (ไม่เลือก c งานอัตโนมัติ/คนนอก) QB-actor-02: พนักงานขายทำอะไร "ไม่ได้" → c) ใช้ได้เฉพาะงานหน้าร้าน (ขาย + สมัคร/ค้นหาสมาชิก) ห้ามจัดการสต็อก/โปรโมชั่น/พนักงาน และดูรายงาน + b) ห้ามทำสิ่งที่ย้อนกลับไม่ได้ (เช่น ยกเลิก/แก้บิลที่ชำระแล้ว แก้ราคาหน้าขาย ลบสินค้า) QB-lang-01: "ออเดอร์" (SRC-001 บรรทัด 15) กับ "บิลขาย" (SRC-001 บรรทัด 33) เป็นสิ่งเดียวกันไหม → a) สิ่งเดียวกัน — ใช้คำเดียวทั้งเอกสาร โค้ด และ UI
