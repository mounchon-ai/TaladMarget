## เนื้อความ

> QB-aud-01 (สต็อก): เจ้าของร้านแก้จำนวนคงเหลือด้วยมือ (นับสต็อกใหม่ ของเน่า/เสีย รับของเข้า) เก็บร่องรอยยังไง → b) เก็บเป็นรายการปรับสต็อกแยก ⭐ — ทุกครั้งที่แก้เกิดรายการ +/− จำนวน พร้อมคนทำ เวลา เหตุผล QB-aud-01 (ราคาสินค้า): เจ้าของร้านแก้ราคาสินค้าในระบบ เก็บร่องรอยยังไง → b) เก็บประวัติราคา ค่าเดิมคงไว้ ⭐ — ทุกครั้งที่แก้เกิดแถวประวัติ (ราคาเดิม → ราคาใหม่ คนแก้ เวลา) ตามต่อ QB-aud-01 (ยกเลิกบิล): บิลที่ยกเลิกแล้วต้องแสดงอะไรบ้าง → a) ผู้ยกเลิก + เวลา + เหตุผล
