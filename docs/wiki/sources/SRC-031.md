## เนื้อความ

> ①a ส่วนลด % ต่อสินค้า (ส้ม 3 ชิ้น ลด 7%) → a) คิดทั้งบรรทัด ปัดครั้งเดียว — ส่วนลด = round(ราคา × จำนวน × % / 100) ①b ส่วนลด % ทั้งบิล (คิดตาม CALC-talad-001) มีเงื่อนไขยอดขั้นต่ำไหม → b) มียอดขั้นต่ำ — เจ้าของตั้งยอดขั้นต่ำเอง เทียบกับยอดหลังโปรระดับสินค้า ①c มีโปรส่วนลดทั้งบิลมากกว่าหนึ่งอันมีผลพร้อมกัน → a) ใช้อันที่ลดมากสุดอันเดียว ②–⑤ → ใช้เดียวกับ CALC-talad-001/002 ทุกข้อ: ราคา money(2) · จำนวน int · % เต็ม 0–100 · decimal · HALF_UP · ปัดทันทีที่คำนวณส่วนลด ที่ 0.01 ⑥ residual_policy → null — ส่วนลดต่อสินค้าคิดทั้งบรรทัดปัดครั้งเดียว ส่วนลดทั้งบิลไม่กระจายลงรายการ ⑦ boundary_behavior → ยืนยันทั้ง 4 ข้อ: ยอดเท่ากับขั้นต่ำพอดี (500.00) ได้ลด 499.99 ไม่ได้ · ขั้นต่ำเทียบกับยอดหลังโปรระดับสินค้า (ไม่นับส่วนลดสมาชิกซึ่งคิดทีหลัง) · หลายโปรบิลเลือกจากโปรที่ครบขั้นต่ำเท่านั้น ลดเท่ากันได้อันไหนก็ได้ · % = 0 ส่วนลด 0 · % = 100 ลดเต็มยอดฐาน ยอดไม่ติดลบ
