# REQ-talad-001

## เป้าหมาย
เลือกสินค้าจากการ์ดพร้อมรูปภาพ หรือค้นหาด้วยชื่อ/บาร์โค้ด ใส่ตะกร้า แล้วชำระเงินได้ง่ายและเร็ว

**actor:** พนักงานขาย · **ความสำคัญ:** high · **มีหน้าจอ:** ใช่ · **สถานะ:** draft

## คุณค่าทางธุรกิจ
พนักงานขายผ่านหน้าจอได้ทุกบิล ไม่ต้องคิดเงินด้วยมือ · ทุกการขายผ่านระบบ ไม่ต้องจดยอดขาย คิดส่วนลด หรือนับตัดสต็อกด้วยมืออีก (เป้าหมายปลายทางของโมดูล — SRC-002 QB-goal-01)

## ความเป็นมา

ข้อกำหนดร่วมของทั้งระบบ (บันทึกไว้ที่นี่ตามที่ตกลงในรอบแบ่ง REQ):
- เป็นระบบสำหรับร้านค้าเดี่ยว (single store) ไม่ต้องรองรับหลายสาขาในเวอร์ชันนี้
- เว็บ responsive รองรับหลายขนาดหน้าจอ · เมนูนำทางด้านซ้าย (left nav menu)
- Tech: web = React + Tailwind v5 + daisy v4 · api = .NET 10 API · database = PostgreSQL v18 (บันทึกตามต้นฉบับ)

นอกขอบเขตรอบนี้ (ตกลงใน /req:ask ชั้น 1 รอบ A — SRC-002):
- การขายผลไม้แบบชั่งน้ำหนัก (ราคาต่อกิโล) — ยกไปรอบถัดไป รอบนี้ขายเป็นหน่วยนับ (ชิ้น/แพ็ก) เท่านั้น
- หลายสาขา — ส่วนขยายในอนาคต ตัดออกแล้วยังบรรลุเป้าหมายปลายทาง

เพิ่มเข้าขอบเขต (ไม่มีในเอกสารต้นทาง — SRC-007 QB-frz-02):
- ออกใบเสร็จให้ลูกค้าทุกบิลขาย (รูปแบบใบเสร็จ เครื่องพิมพ์ และใบกำกับภาษี ยังไม่ได้ตกลง)

### [BR-talad-026@v1](../rules/BR-talad-026@v1.md) · ทุกบิลขายที่ชำระเงินสำเร็จออกใบเสร็จให้ลูกค้า — หลังชำระ หน้าจอแสดงใบเสร็จเต็มจอพร้อมปุ่มพิมพ์ (พนักงานกดพิมพ์เมื่อลูกค้าต้องการ) กดปิดแล้วจึงได้ตะกร้าว่างใบใหม่ · เมื่อยกเลิกบิล ใบเสร็จเดิมถือว่ายกเลิกและพิมพ์ซ้ำไม่ได้ · บิลที่ขายใหม่แทนออกใบเสร็จเลขใหม่ ไม่อ้างถึงใบเดิม
- **ชนิด:** policy · **สถานะ:** draft · **วิธีออกแบบเทสต์:** state_transition
