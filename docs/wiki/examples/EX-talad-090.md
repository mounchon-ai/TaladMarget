# EX-talad-090

## กำหนดให้ (given)
สมาชิก ปรีชา ดีงาม เบอร์ 0861112222 สมัครไว้แต่ยังไม่เคยซื้อ (ไม่มีบิลขายผูก) · เจ้าของร้านล็อกอินอยู่ · เจ้าของร้านลบสมาชิก ปรีชา ดีงาม ไปแล้ว

## เมื่อ (when)
สมชายสมัครสมาชิกใหม่ ชื่อ "ปรีชา ดีงาม" เบอร์โทร "0861112222" แล้วกดบันทึก

## แล้ว (then)
ระบบแสดง "สมัครสมาชิกสำเร็จ" · ค้นหาเบอร์ 0861112222 ที่หน้าขายเจอ ปรีชา ดีงาม ยอดซื้อสะสม 0 บาท

## พิสูจน์กฎ

- [BR-talad-040@v2](../rules/BR-talad-040@v2.md) ✅ ปัจจุบัน — สมาชิกทุกคน ไม่ว่ามีบิลขายผูกอยู่หรือไม่ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่ซ่อน — ค้นหาที่หน้าขายไม่เจออีก แต่บิลเก่า (ถ้ามี) ยังแสดงชื่อสมาชิกครบ · เบอร์ของสมาชิกที่ถูกซ่อนถูกปล่อย สมัครใหม่ด้วยเบอร์นั้นได้เป็นสมาชิกคนใหม่ ยอดซื้อสะสมเริ่มที่ 0
