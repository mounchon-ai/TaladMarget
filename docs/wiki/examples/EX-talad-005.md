# EX-talad-005

## กำหนดให้ (given)
พนักงานขายสมชายอยู่ที่หน้าสมัครสมาชิก · ยังไม่มีสมาชิกเบอร์ 0812345678

## เมื่อ (when)
กรอกชื่อ "สมหญิง ใจดี" เบอร์โทร "0812345678" แล้วกดบันทึก

## แล้ว (then)
ระบบแสดง "สมัครสมาชิกสำเร็จ" · ค้นหาเบอร์ 0812345678 ที่หน้าขายเจอสมาชิก สมหญิง ใจดี

## พิสูจน์กฎ

- [BR-talad-002@v1](../rules/BR-talad-002@v1.md) ✅ ปัจจุบัน — สมัครสมาชิกต้องกรอกทั้งเบอร์โทรและชื่อ — ขาดอย่างใดอย่างหนึ่งสมัครไม่ได้ · เบอร์โทรต้องเป็นตัวเลข 10 หลักขึ้นต้นด้วย 0 ทั้งตอนสมัครและตอนแก้เบอร์
- [BR-talad-030@v1](../rules/BR-talad-030@v1.md) ✅ ปัจจุบัน — เบอร์โทรสมาชิกห้ามซ้ำกับสมาชิกที่ยังใช้งานอยู่ — เบอร์โทรหนึ่งเบอร์เป็นของสมาชิกที่ใช้งานอยู่ได้คนเดียว · สมัครด้วยเบอร์ที่มีสมาชิกใช้อยู่แล้ว (รวมถึงกดบันทึกซ้ำ) หรือแก้เบอร์ให้ไปซ้ำกับสมาชิกคนอื่น ไม่สำเร็จ และระบบแจ้ง error · สมาชิกที่ถูกซ่อนตาม BR-talad-040 ไม่นับตอนตรวจซ้ำ
