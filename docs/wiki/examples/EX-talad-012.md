# EX-talad-012

## กำหนดให้ (given)
มีสมาชิก สมหญิง ใจดี เบอร์ 0812345678 ซึ่งมีบิลขายผูกอยู่ 1 บิล (ขายโดยสมชาย ยอด 250 บาท) · เจ้าของร้านล็อกอินอยู่

## เมื่อ (when)
เจ้าของร้านลบสมาชิก สมหญิง ใจดี แล้วพนักงานขายสมชายค้นหาสมาชิกที่หน้าขายด้วยเบอร์ "0812345678" และด้วยชื่อ "สมหญิง"

## แล้ว (then)
ค้นหาทั้งสองแบบไม่เจอ สมหญิง ใจดี — ผูกสมาชิกคนนี้กับตะกร้าใหม่ไม่ได้

## พิสูจน์กฎ

- [BR-talad-040@v1](../rules/BR-talad-040@v1.md) ❄️ — สมาชิกที่มีบิลขายผูกอยู่แล้ว เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่ซ่อน — ค้นหาที่หน้าขายไม่เจออีก แต่บิลเก่ายังแสดงชื่อสมาชิกครบ · เบอร์ของสมาชิกที่ถูกซ่อนถูกปล่อย สมัครใหม่ด้วยเบอร์นั้นได้เป็นสมาชิกคนใหม่ ยอดซื้อสะสมเริ่มที่ 0
- [BR-talad-040@v2](../rules/BR-talad-040@v2.md) ✅ ปัจจุบัน — สมาชิกทุกคน ไม่ว่ามีบิลขายผูกอยู่หรือไม่ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่ซ่อน — ค้นหาที่หน้าขายไม่เจออีก แต่บิลเก่า (ถ้ามี) ยังแสดงชื่อสมาชิกครบ · เบอร์ของสมาชิกที่ถูกซ่อนถูกปล่อย สมัครใหม่ด้วยเบอร์นั้นได้เป็นสมาชิกคนใหม่ ยอดซื้อสะสมเริ่มที่ 0
