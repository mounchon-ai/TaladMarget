# EX-talad-064

## กำหนดให้ (given)
บิลขาย: ส้มสายน้ำผึ้ง จำนวน 2 (90 บาท) เข้าโปรโมชั่นลด 10% ชำระ 81 บาท

## เมื่อ (when)
เจ้าของร้านลบโปรโมชั่นนั้น แล้วเปิดบิลเดิม

## แล้ว (then)
บิลเดิมยังแสดงส่วนลด 9 บาท ยอดชำระ 81 บาท — ข้อมูลโปรโมชั่นที่บิลอ้างถึงไม่หายไปพร้อมการลบ

## พิสูจน์กฎ

- [BR-talad-036@v1](../rules/BR-talad-036@v1.md) ✅ ปัจจุบัน — ราคาสินค้า โปรโมชั่น และ % ส่วนลดสมาชิกเก็บเป็นเวอร์ชัน — บิลขายอ้างถึงเวอร์ชันที่ใช้ตอนขาย และเวอร์ชันที่บิลอ้างถึงแล้วลบไม่ได้
- [BR-talad-037@v1](../rules/BR-talad-037@v1.md) ✅ ปัจจุบัน — สินค้าหรือโปรโมชั่นทุกรายการ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่เปลี่ยนเป็นเลิกขาย ไม่ว่าเคยถูกขายในบิลแล้วหรือไม่ — หายจากหน้าขายและหน้าจัดการ แต่บิลเก่ายังแสดงสินค้า ราคา และส่วนลดเดิมครบ · สินค้าที่อยู่ในตะกร้าที่ยังเปิดอยู่เมื่อถูกลบ ชำระไม่ได้ ระบบแสดง "<ชื่อสินค้า> เลิกขายแล้ว กรุณาเอาออกจากตะกร้า"
