# EX-talad-089

## กำหนดให้ (given)
สมาชิก ปรีชา ดีงาม เบอร์ 0861112222 สมัครไว้แต่ยังไม่เคยซื้อ (ไม่มีบิลขายผูก) · เจ้าของร้านล็อกอินอยู่

## เมื่อ (when)
เจ้าของร้านลบสมาชิก ปรีชา ดีงาม แล้วพนักงานขายสมชายค้นหาสมาชิกที่หน้าขายด้วย "0861112222" และด้วยชื่อ "ปรีชา"

## แล้ว (then)
ค้นหาทั้งสองแบบไม่เจอ ปรีชา ดีงาม — ผูกสมาชิกคนนี้กับตะกร้าไม่ได้

## พิสูจน์กฎ

- [BR-talad-040@v2](../rules/BR-talad-040@v2.md) ✅ ปัจจุบัน — สมาชิกทุกคน ไม่ว่ามีบิลขายผูกอยู่หรือไม่ เมื่อเจ้าของร้านกดลบ ระบบไม่ลบจริงแต่ซ่อน — ค้นหาที่หน้าขายไม่เจออีก แต่บิลเก่า (ถ้ามี) ยังแสดงชื่อสมาชิกครบ · เบอร์ของสมาชิกที่ถูกซ่อนถูกปล่อย สมัครใหม่ด้วยเบอร์นั้นได้เป็นสมาชิกคนใหม่ ยอดซื้อสะสมเริ่มที่ 0
