# CALC-talad-008@v1

## สูตร

```
free = บรรทัดทั้งหมดในตะกร้า ; applied = [] ; loop { cand = { (p, disc_p, lines_p) | p ∈ โปรระดับสินค้าที่เปิดอยู่ , disc_p = ส่วนลดรวมของ p ที่คิดจากบรรทัดใน free ตาม CALC ของ p (003–007 · ปัดแล้ว) , disc_p > 0 } ; if cand ว่าง → break ; top = { c ∈ cand | c.disc = max(cand.disc) } ; pick = top ถ้ามีตัวเดียว · พนักงานเลือกจาก top ถ้ามีหลายตัว ; applied += pick ; free −= pick.lines (ทั้งบรรทัด) }   — item_promo_discount ของแต่ละบรรทัด (CALC-talad-001) มาจาก pick ที่ใช้บรรทัดนั้น · บรรทัดที่เหลือใน free ได้ 0 · ส่วนลดทั้งบิลคิดทีหลังตาม CALC-talad-001/003
```

ผูกกับกฎ [BR-talad-029@v1](../rules/BR-talad-029@v1.md)

## ตัวแปรเข้า

| ชื่อ | ชนิด | ความหมาย |
|---|---|---|
| `lines[]` | { product , qty int , unit_price money(2) } | บรรทัดในตะกร้า · ราคา ณ ตอนกดชำระ (BR-talad-038) |
| `promos[]` | โปรระดับสินค้าที่เปิดอยู่ ณ ตอนกดชำระ | แต่ละโปรมีชนิด (BR-talad-009/011/012/013/014) และพารามิเตอร์ของชนิดนั้น · คิดส่วนลดด้วย CALC ของชนิดนั้น |
| `staff_choice` | promo id | โปรที่พนักงานเลือก ใช้เฉพาะเมื่อโปรที่ลดมากสุดลดเท่ากันพอดีตั้งแต่ 2 โปร |

## พฤติกรรมที่ขอบ

- ไม่มีโปรเข้าเงื่อนไข → ไม่ลด ทุกบรรทัด item_promo_discount = 0.00
- เข้าโปรเดียว → ใช้โปรนั้น
- โปรที่ลด 0 (y = 0 หรือยังไม่ครบชุด) ไม่ถูกเลือก และไม่กินบรรทัด
- โปรที่ลดมากสุดลดเท่ากันพอดี → พนักงานเลือก
- เทียบด้วยค่าหลังปัด — ต่างกัน 0.01 ก็นับว่ามากกว่า
- โปรได้บรรทัดไปทั้งบรรทัด — ชิ้นนอกชุดคิดราคาปกติ ไม่เข้าโปรอื่น
- ราคาใช้ค่า ณ ตอนกดชำระ (BR-talad-038)
