ข้อมูลสมาชิก

ดูและแก้ชื่อหรือเบอร์โทรของสมาชิก และให้เจ้าของร้านซ่อนสมาชิก

visible to: ROLE-001 (พนักงานขาย), ROLE-002 (เจ้าของร้าน/ผู้ดูแล)

ยอดซื้อสะสม
แสดงค่าจากระบบ อ่านอย่างเดียว (ENT-004.accumulatedAmount)

→ หน้าสมาชิก

states

empty (does not occur)
ไม่เกิด — หน้าเปิดจากสมาชิกที่มีอยู่เสมอ
loading
แสดงโครงฟอร์มระหว่างโหลด · ปุ่มบันทึกถูกปิดระหว่างบันทึก
error
บันทึกไม่ผ่าน: แสดงข้อความใต้ช่องที่ผิด ค่าเดิมในระบบไม่เปลี่ยน · สมาชิกถูกซ่อนไปแล้วระหว่างเปิดหน้า: แจ้ง "ไม่พบสมาชิก" และกลับรายการ
unauthorized (does not occur)
ไม่เกิดสำหรับผู้ที่ล็อกอินแล้ว — ทั้งสองบทบาทเปิดได้ แต่พนักงานขายไม่เห็นปุ่มลบสมาชิก และ API ปฏิเสธถ้าเรียกตรง (BR-talad-019@v1) · ยังไม่ล็อกอิน: พาไปหน้าเข้าสู่ระบบ
overflow
ข้อความยาวเกินช่อง: ช่องเลื่อนภายในตัวเอง ไม่ดันรูปหน้า · ไม่มีรายการยาวบนหน้านี้
