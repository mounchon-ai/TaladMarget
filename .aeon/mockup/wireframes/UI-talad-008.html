states

empty (does not occur)
ไม่เกิด — หน้าเปิดจากบิลที่มีอยู่เสมอ
loading
แสดงโครงบิลระหว่างโหลด
error
โหลดข้อมูลไม่สำเร็จ แสดงข้อความ "โหลดข้อมูลไม่สำเร็จ" พร้อมปุ่มลองใหม่ ข้อมูลที่กรอกค้างไว้ไม่หาย
unauthorized
พนักงานขายเปิดบิลของคนอื่นตรง ๆ: API ปฏิเสธและพากลับประวัติการขายพร้อม "คุณไม่มีสิทธิ์เข้าถึงหน้านี้" ไม่แสดงข้อมูลบิล (BR-talad-018@v1) · ยังไม่ล็อกอิน: พาไปหน้าเข้าสู่ระบบ
overflow
