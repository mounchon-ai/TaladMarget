เพิ่ม/แก้ไขสินค้า

เจ้าของร้านเพิ่มสินค้าใหม่ หรือแก้ชื่อ บาร์โค้ด รูป และจุดเตือนของสินค้า

visible to: ROLE-002 (เจ้าของร้าน/ผู้ดูแล)

states

empty (does not occur)
ไม่เกิด — ฟอร์มว่างคือสภาพเริ่มต้นของการเพิ่มสินค้า
loading
ปุ่มบันทึกถูกปิดระหว่างบันทึก · อัปโหลดรูปแสดงความคืบหน้า
error
แสดงข้อความใต้ช่องที่ผิด (ชื่อว่าง · ราคาไม่มากกว่า 0 · บาร์โค้ดซ้ำ) ไม่มีอะไรถูกบันทึก
unauthorized
พนักงานขายเปิดหน้านี้ตรง ๆ ถูกพากลับหน้าขายและแสดง "คุณไม่มีสิทธิ์เข้าถึงหน้านี้" โดยไม่แสดงข้อมูลใดของหน้านี้ (BR-talad-018@v1) · ยังไม่ล็อกอิน: พาไปหน้าเข้าสู่ระบบ
overflow
ไฟล์รูปเกิน 2 MB หรือไม่ใช่ JPG/PNG/WebP: ปฏิเสธและแจ้งชนิดและขนาดที่รับได้ · ชื่อยาวเลื่อนในช่อง
